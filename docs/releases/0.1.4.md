# Absolutex 0.1.4

A beta comic and book reader for Android 13+, arm64.

## What's new

- **CB7/7z opens.** LZMA/LZMA2 decoding uses pinned xz 5.8.4. Small and 83 MB solid and non-solid
  archives were checked on a OnePlus 11R. Encrypted 7z is still unsupported.
- **Large solid 7z archives decode once in the background.** On a laptop and one 300-page solid
  CB7 on a OnePlus 11R the first page appeared in about 0.5 s; other archives and phones untested.
  Archives that cannot use the cache fall back to direct extraction.
- **Open a file.** A home-header button opens the system picker; clearer empty states distinguish
  an empty library, scanning, unreadable folders and a scan with no books. More VIEW filters let
  file managers offer Absolutex for supported archive types.
- **Backup and restore.** Settings → Backup exports reading data and preferences as JSON through
  Android's system picker. Restore merges into existing data and can be repeated safely. Export
  results show counts. The file contains book names. Server records, credentials and folder grants
  are excluded, as are the tap-guide flag and text-EPUB position within a chapter; a restored text
  EPUB reopens at its chapter start. Room and settings restore in ordered phases; settings failure
  after reading-data restore is reported and re-import retries the rest.
- **Reader fixes.** Turning off Trim margins keeps Match background working, option chips wrap,
  the password dialog avoids password-manager autofill, and Cancel leaves the reader.
- **Safer scans.** A scan that cannot read a folder preserves its books instead of deleting rows.
- **Recent and page counts.** Opening a book puts it in Recent/Continue reading without inventing
  progress or a page-read statistic. Learned page counts refresh and survive unchanged rescans.
  The upgrade removes old Mark-unread (page 0) progress rows and keeps learned page counts;
  old backups do not recreate those unread rows as started books.
- **Clearer headers.** Home actions align, Open file has a clearer icon, and Settings has the
  SETTINGS title with a back arrow.
- **One-tap Enhance.** Bitmap/PDF reader chrome offers a gentle preset, off by default: Mitchell
  upscaling, contrast 1.05 and vibrance 0.05. Turning it off restores saved custom values; editing
  advanced colour/upscaler controls in app Settings turns it off. Text EPUB does not show Enhance.
  Strengths were judged by eye on one page only, not across a representative collection.

## Known limitations

- No automatic updates. Use Obtainium or watch repository releases.
- Komga/Kavita progress sync and cloud storage are not available; offline copies are not connected.
- Encrypted CB7/7z and AES-encrypted ZIPs are unsupported. Password-protected RAR/CBR remains unverified.
- One measurement on 30 September 2026 on a OnePlus 11R after paging and jumping through a
  564 MB CBR: about 171 MB process PSS (183 MB right after seek jumps); the project budget is
  150 MB. This is distinct from the earlier 150 MB measurement after 12 page turns.
- Picked library folders rescan when the library opens or Rescan is requested; no live SAF folder sync.
- Forgetting a library folder drops favourites on its rows. A separate favourites table is a follow-up.

## Install

Download `Absolutex-0.1.4.apk` from this release and open it. Allow installation from your browser
or file manager when Android asks. Android 13 or newer and a 64-bit (arm64) phone are required.
Version 0.1.3 updates in place with the same signing key.

Downgrading from 0.1.4 to 0.1.3 is not supported; the older build cannot open the upgraded database.

## Found a problem?

[Open an issue](https://github.com/therahul-yo/Absolutex/issues/new/choose) with your phone model,
Android version and file format if a book will not open.
